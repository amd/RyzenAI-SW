## Keeping the tables up to date

- Source of truth: the AMD Hugging Face collections for Ryzen AI 1.7.1.
- `.github/scripts/fetch_models.py` re-reads those collections and regenerates the block above.
- The `Update Model List` workflow runs it on a schedule and opens a PR when the collections change.
- **Owner:** @uday610 keeps the model tables accurate.
