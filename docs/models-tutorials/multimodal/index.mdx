# Multimodal

Deploy multimodal AI pipelines combining NPU and GPU on Ryzen AI.

Multimodal models support vision-language tasks (VLMs), combining image understanding with natural language. These models can process images and answer questions, generate captions, or perform other joint vision-language tasks.
