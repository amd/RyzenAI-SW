# 👋 Welcome

---

AMD Ryzen™ AI Software is the toolkit for building and deploying AI applications on AMD Ryzen™ AI powered PCs. It provides everything you need to run inference on the neural processing unit (NPU), integrated GPU, and discrete GPU — all from a single, unified stack.

Whether you are prototyping an LLM chatbot, deploying a vision pipeline, or integrating speech-to-text, Ryzen AI Software gets you from a pre-trained model to a working application in minutes.

## 📝 What You'll Learn

- **[🚀 Getting Started](/getting-started)** — Install the SDK, run your first model on the NPU, and understand the hardware landscape.
- **[💻 Applications with Ryzen](/applications)** — Explore AI-powered desktop applications already running on Ryzen AI, from LLM chat to image generation.
- **[🧠 Models & Tutorials](/models-tutorials)** — Browse verified models (LLMs, vision, audio, multimodal) and follow step-by-step tutorials.
- **[🔧 Tools](/develop)** — Use developer tools like Quark quantization, AI Analyzer, NPU management, and the CVML library.
- **[📖 Reference](/reference)** — Changelog, supported operators, model list, and licenses.
