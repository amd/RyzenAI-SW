## When to use the GPU vs the NPU

- **NPU** - best for sustained, power-efficient inference (CNNs, transformers, LLM hybrid/NPU flows).
- **GPU (Radeon)** - best for high-throughput workloads, larger models via GGUF/Vulkan, and ROCm-accelerated pipelines.
- **Hybrid** - LLM flows can split work across NPU and iGPU for the best time-to-first-token and tokens-per-second.
