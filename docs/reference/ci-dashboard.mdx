This page tracks the documentation CI pipeline: which checks ran, when, what passed or failed, and the owner responsible for each page. The data comes from `.github/scripts/ci-history.json`, which CI appends to on every run.

<Note>
The runs below are **real executions** recorded by `.github/scripts/record_run.py` (not mock data). Cloud-stage checks (link check, page build, code-block syntax + execution of `test`-tagged blocks) run on each PR. NPU-hardware execution of `test`-tagged blocks runs on the self-hosted Strix / Strix Halo runners; those rows appear here once that runner is connected.
</Note>

## How the pipeline works

| Stage | What runs | Where |
|-------|-----------|-------|
| Link + build | `mint broken-links`, `mint validate` | cloud |
| Prose + spelling | Vale, cspell | cloud |
| Code blocks | `extract_code_blocks.py` (syntax always; `test`-tagged blocks executed on hardware) | cloud + Strix / Strix Halo |
| Failure routing | `notify_owner.py` opens an issue that @mentions the owner (GitHub notifies them) | cloud |
| Record | `record_run.py` appends the run here | cloud |
